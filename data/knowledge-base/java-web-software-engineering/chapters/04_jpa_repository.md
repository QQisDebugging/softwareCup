# 第四章 数据库建模、JPA 与 Repository

## 学习目标

- 掌握实体建模和关系数据库表设计基础。
- 理解 JPA 实体、Repository 和事务边界。
- 能够实现基础 CRUD 数据访问。

## 先修知识

- Java 类与对象
- SQL 基础
- Spring Boot Controller 基础

## 核心概念

- 实体建模
- JPA
- Repository
- 事务

## 关键知识点

- 实体类映射数据库表，字段映射表列。
- Repository 封装常用数据访问操作。
- Service 层通常定义事务边界。
- 数据库约束能保证数据一致性。

## 示例场景

为课程和学习资源设计数据表，使用 Repository 查询课程下的资源列表。

## 常见错误

- 实体关系设计过度复杂。
- 在 Controller 里直接调用 Repository。
- 忽视事务导致多步写入不一致。

## 实操任务

- 设计课程表和学习资源表。
- 实现课程资源查询接口。

## 适合的学生画像

- 数据库基础弱的学生适合先画 ER 图。
- 工程实践型学生适合完成实体到接口的全链路。

## 推荐资源类型

- ER 图
- JPA 实体示例
- Repository 查询练习

## 测评建议

- 通过建模题检查学生是否能识别主键、外键和索引。
