# 第二章 HTTP、REST API 与 JSON 契约

## 学习目标

- 理解 HTTP 请求响应模型。
- 掌握常见 HTTP 方法、状态码和 REST API 设计原则。
- 能够设计稳定的 JSON 请求和响应契约。

## 先修知识

- Web 基础概念
- 浏览器访问网页的基本流程

## 核心概念

- HTTP 方法
- 状态码
- REST API
- JSON 契约

## 关键知识点

- GET 通常用于查询资源，POST 通常用于创建或提交操作。
- 状态码用于表达请求处理结果。
- REST API 强调围绕资源设计路径和操作。
- JSON 契约需要保持字段命名、类型和错误格式稳定。

## 示例场景

学生设计课程列表、课程详情、资源生成任务创建等接口，并约定前端如何传参和解析响应。

## 常见错误

- 所有操作都使用 POST，接口语义不清。
- 响应字段不稳定，导致前端频繁适配。
- 错误响应没有统一格式。

## 实操任务

- 设计课程资源查询和创建接口。
- 写出请求体、响应体和错误响应样例。

## 适合的学生画像

- 接口概念薄弱学生适合使用路径和方法对照表。
- 前后端协作困难学生适合先写接口契约再编码。

## 推荐资源类型

- REST API 设计表
- JSON 契约示例
- 接口测试题

## 测评建议

- 通过接口设计题检查学生是否能正确选择 HTTP 方法和状态码。
