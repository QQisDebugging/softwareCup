# 第六章 文件上传与资源管理

## 学习目标

- 理解 Web 文件上传的基本流程。
- 掌握 Multipart 请求、文件存储和元数据保存。
- 能够设计上传大小、类型和用途限制。

## 先修知识

- REST API
- Controller 与 Service 分层
- 数据库建模

## 核心概念

- Multipart
- 文件存储
- 元数据
- 安全限制

## 关键知识点

- 文件内容和文件元数据需要分别处理。
- 后端应限制文件大小、类型和保存路径。
- 数据库保存原文件名、内容类型、大小、存储路径和用途。
- 上传接口需要考虑错误提示和前端交互体验。

## 示例场景

学生上传课程资料，系统保存文件并记录元数据，后续智能体可以读取这些资料生成个性化资源。

## 常见错误

- 直接使用用户上传的文件名作为保存路径。
- 不限制文件大小和类型。
- 只保存文件，不保存可查询的元数据。

## 实操任务

- 实现文件上传接口。
- 保存上传文件的元数据信息。

## 适合的学生画像

- 安全意识薄弱学生适合学习文件名和路径安全。
- 实践型学生适合完成上传到查询的完整流程。
