# 第十章 部署、配置与演示交付

## 学习目标

- 理解配置文件、数据库环境和部署流程。
- 掌握本地演示和常规运行环境的差异。
- 能够整理项目交付材料和演示检查清单。

## 先修知识

- Spring Boot 启动流程
- 数据库和前端构建基础

## 核心概念

- 配置文件
- 数据库切换
- 部署
- 演示验收

## 关键知识点

- 配置应区分本地开发、测试和演示环境。
- H2 适合快速本地演示，PostgreSQL 更适合稳定部署。
- 前端构建产物和后端服务需要明确端口和 API 地址。
- 演示前应检查数据、服务、接口、页面和兜底策略。

## 示例场景

比赛演示前，团队启动 Python 智能体、Spring Boot 后端和 Vue 前端，并准备好课程数据、学生画像和生成任务样例。

## 常见错误

- 环境变量遗漏导致服务无法连接。
- 演示数据没有提前准备。
- 前端 API 地址仍指向错误端口。

## 实操任务

- 编写本地演示启动清单。
- 验证 H2 和 PostgreSQL 两种数据库配置。

## 适合的学生画像

- 交付经验不足学生适合使用演示检查表。
- 运维兴趣学生适合扩展 Docker 部署方案。

## 推荐资源类型

- 部署流程图
- 环境变量清单
- 演示验收表

## 测评建议

- 检查学生是否能说明一个 Web 项目从源码到可演示系统需要哪些步骤。
