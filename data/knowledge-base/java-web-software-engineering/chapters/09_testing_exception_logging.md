# 第九章 测试、异常处理与日志

## 学习目标

- 理解接口测试、异常处理和日志对项目交付的价值。
- 掌握统一异常响应和基础测试思路。
- 能够根据日志定位常见问题。

## 先修知识

- Spring Boot 接口开发
- 数据库访问基础

## 核心概念

- 接口测试
- 异常处理
- 日志
- 调试

## 关键知识点

- 接口测试用于验证输入、输出和异常分支。
- 统一异常处理能让前端获得稳定错误信息。
- 日志应包含足够上下文，但不应泄露敏感信息。
- 调试时应先定位请求路径、参数、服务层逻辑和数据库状态。

## 示例场景

课程 ID 不存在时，后端返回统一 404 错误，前端展示可理解的错误提示，日志记录具体缺失 ID。

## 常见错误

- 把异常堆栈直接返回给前端。
- 没有测试异常分支。
- 日志只写“失败”，没有上下文。

## 实操任务

- 实现统一 404 错误响应。
- 为课程查询接口补充成功和失败测试。

## 适合的学生画像

- 调试能力弱的学生适合使用错误定位流程图。
- 工程实践型学生适合补齐接口测试用例。

## 推荐资源类型

- 异常响应格式示例
- 测试用例清单
- 日志定位流程图

## 测评建议

- 通过错误案例检查学生是否能定位 Controller、Service、Repository 中的问题边界。
