# 第七章 异步任务、状态机与进度追踪

## 学习目标

- 理解长耗时任务为什么需要异步执行。
- 掌握任务状态机、任务步骤和进度记录。
- 认识 SSE 在进度推送中的作用。

## 先修知识

- Spring Boot Service
- 数据库事务
- HTTP 请求响应模型

## 核心概念

- 异步任务
- 状态机
- SSE
- 任务步骤

## 关键知识点

- 长耗时任务不应阻塞普通 HTTP 请求。
- 状态机用于表达 PENDING、RUNNING、SUCCEEDED、FAILED 等任务状态。
- 任务步骤可以记录多智能体执行链路。
- SSE 可以把进度事件实时推送给前端。

## 示例场景

资源生成任务需要经历画像分析、知识诊断、路径规划、文档生成、题库生成、安全审核等步骤，前端需要实时看到进度。

## 常见错误

- 创建任务后没有状态记录。
- 异常时不更新失败状态。
- 前端长时间白屏等待。

## 实操任务

- 设计资源生成任务状态机。
- 实现任务步骤记录和 SSE 进度接口。

## 适合的学生画像

- 后端基础较好的学生适合挑战异步任务。
- 交互体验敏感学生适合关注进度可视化。

## 推荐资源类型

- 状态机图
- SSE 调用示例
- 任务步骤表

## 测评建议

- 检查学生是否能说明异步任务和普通同步接口的区别。
