# 第八章 前后端联调：Vue3、Axios 与接口封装

## 学习目标

- 理解前端页面如何调用后端 REST API。
- 掌握 Axios 实例、错误处理和 API 模块封装。
- 能够把后端数据展示到 Vue3 页面中。

## 先修知识

- JavaScript 基础
- REST API 与 JSON 契约
- Vue 基础

## 核心概念

- Vue3
- Axios
- API 封装
- 错误处理

## 关键知识点

- API 基础地址应通过环境变量配置。
- Axios 拦截器可以统一处理响应和错误。
- 前端模块化 API 封装能降低页面复杂度。
- 前端需要对空数据、加载态和错误态做展示。

## 示例场景

前端课程页面调用 `/api/courses` 展示课程列表，任务页面调用 `/api/tasks/{taskId}/steps` 展示生成步骤。

## 常见错误

- 页面直接散落大量接口地址。
- 没有处理后端连接失败。
- 类型定义和后端响应不一致。

## 实操任务

- 封装课程列表 API。
- 在 Vue 页面展示加载、成功和失败三种状态。

## 适合的学生画像

- 前端基础弱学生适合先看 API 调用流程图。
- 工程实践型学生适合完成页面到后端的闭环联调。

## 推荐资源类型

- Axios 封装示例

## 测评建议

- 检查学生是否能定位前端连接失败是 URL、端口还是后端异常问题。
