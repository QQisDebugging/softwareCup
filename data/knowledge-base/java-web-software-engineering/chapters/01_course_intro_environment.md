# 第一章 课程导论与工程环境

## 学习目标

- 理解 Java Web 综合实践课程的学习目标和项目交付要求。
- 完成 Git、JDK、Maven 和 IDE 的基础环境准备。
- 建立从需求、接口、数据库到前端联调的工程化学习路线。

## 先修知识

- Java 基础语法
- 命令行基础
- Git 基础概念

## 核心概念

- 工程环境
- 项目结构
- 版本管理
- 构建工具

## 关键知识点

- Git 用于记录代码版本和协作提交。
- JDK 是 Java 项目编译和运行的基础。
- Maven 负责依赖管理、构建和测试执行。
- IDE 能提升编码、调试和项目导航效率。

## 示例场景

学生从零开始拉取一个 Spring Boot 项目，配置 JDK 和 Maven 后运行健康检查接口，形成第一次可验证交付。

## 常见错误

- JDK 版本和项目要求不一致。
- Maven 依赖下载失败后不知道查看错误日志。
- 只会运行项目，但不了解目录结构。

## 实操任务

- 配置 JDK、Maven 和 IDE。
- 克隆项目并运行后端健康检查接口。

## 适合的学生画像

- 基础薄弱学生适合使用环境检查清单。
- 实践型学生适合直接完成项目启动任务。

## 推荐资源类型

- 环境配置清单
- 项目目录图
- 启动错误排查卡片

## 测评建议

- 检查学生是否能说明 JDK、Maven、Git 的作用。
