# 第五章 Flyway 数据库迁移与初始化数据

## 学习目标

- 理解数据库迁移脚本的价值。
- 掌握 Flyway 脚本命名、执行顺序和版本管理。
- 能够用迁移脚本创建表结构和初始化基础数据。

## 先修知识

- SQL 建表基础
- JPA 实体映射基础

## 核心概念

- Flyway
- 迁移脚本
- 初始化数据
- 数据库版本管理

## 关键知识点

- Flyway 通过版本化脚本保证数据库结构可追踪。
- 迁移脚本一旦被环境执行，不应随意修改。
- 初始化数据适合放置资源类型、智能体定义等基础字典。
- JPA 的 `ddl-auto=validate` 可以配合 Flyway 校验实体和表结构。

## 示例场景

项目需要在不同电脑上稳定创建课程、学生画像和任务表，Flyway 能让数据库结构保持一致。

## 常见错误

- 修改已经执行过的迁移脚本。
- 脚本命名不符合版本规则。
- 实体字段和表字段不一致。

## 实操任务

- 编写 `V1__init.sql` 创建课程表。
- 编写初始化资源类型的迁移脚本。

## 适合的学生画像

- 协作经验不足学生适合学习迁移脚本规范。
- 调试型学生适合分析实体和表结构不一致的启动错误。
