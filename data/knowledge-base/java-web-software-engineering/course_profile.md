# Java Web 应用开发与软件工程实践

## 课程定位

本课程面向计算机类、软件工程类本科学生，围绕 Java Web、Spring Boot、数据库、REST API、文件上传、异步任务、前后端联调、测试与部署等内容，构造一门面向真实项目交付的综合实践课程。

## 适用对象

- 具备 Java 基础并希望完成完整 Web 项目的本科生
- 对后端接口、数据库、工程分层、前后端协作不熟悉的学生
- 需要通过项目任务提升工程实践能力的学习者

## 先修要求

- Java 程序设计基础
- 数据库基础
- HTML、CSS、JavaScript 基础
- Git 与命令行基础

## 教学目标

- 掌握 Spring Boot 项目结构、Controller、Service、Repository 分层设计
- 能够设计 REST API 和 JSON 数据契约
- 能够使用 JPA 与 Flyway 完成数据库建模和迁移
- 能够实现文件上传、异步任务、进度追踪和异常处理
- 能够完成 Vue3 前端和 Spring Boot 后端的接口联调

## 个性化资源生成重点

- 对基础薄弱学生：优先生成概念讲解、接口流程图和分层代码模板
- 对实践型学生：优先生成项目任务、验收标准和调试清单
- 对备考型学生：优先生成接口设计题、数据库建模题和错因分析
- 对进阶型学生：优先生成架构优化、可观测性和部署实践案例
