# 实验一 组网与路由器配置

## 实验来源

- 本地参考文件：`D:\实验1组网与路由器配置.pdf`
- 对应章节：第五章 网络层，第四章 广播链路与局域网
- 对应知识点：局域网、IP地址、默认网关、路由表、静态路由、RIP动态路由

## 实验目的

- 掌握交换机、路由器的基本工作原理。
- 学会利用网络设备完成基本组网。
- 掌握主机 IP 地址、子网掩码、默认网关和路由器接口地址配置方法。
- 能够通过静态路由和动态路由实现不同网络主机之间的通信。

## 实验环境

- Cisco Packet Tracer 7.0

## 实验内容

- 局域网组网
- IP 地址配置
- 路由器接口配置
- 静态路由配置
- RIP 动态路由配置
- 跨子网连通性验证

## 实验步骤

### 1. 交换机连接主机

配置两台位于同一局域网的主机：

| 设备 | 接口 | IP 地址 | 子网掩码 |
|---|---|---|---|
| PC0 | FastEthernet | 192.168.0.2 | 255.255.255.0 |
| PC1 | FastEthernet | 192.168.0.3 | 255.255.255.0 |

完成配置后，使用 `ping` 测试两台主机之间的连通性。

### 2. 单路由器连接两个网段

配置两个不同网段的主机和路由器接口：

| 设备 | 接口 | IP 地址 | 子网掩码 | 默认网关 |
|---|---|---|---|---|
| PC0 | FastEthernet | 192.168.1.2 | 255.255.255.0 | 192.168.1.1 |
| PC1 | FastEthernet | 192.168.2.2 | 255.255.255.0 | 192.168.2.1 |
| Router | FastEthernet0/0 | 192.168.1.1 | 255.255.255.0 |  |
| Router | FastEthernet1/0 | 192.168.2.1 | 255.255.255.0 |  |

配置路由器接口地址后，使用 `ping` 测试两个网段主机之间是否连通。

### 3. 两台路由器直连

配置两台路由器及两端主机：

| 设备 | 接口 | IP 地址 | 子网掩码 | 默认网关 |
|---|---|---|---|---|
| PC0 | FastEthernet | 192.168.1.2 | 255.255.255.0 | 192.168.1.1 |
| PC1 | FastEthernet | 192.168.2.2 | 255.255.255.0 | 192.168.2.1 |
| Router0 | FastEthernet0/0 | 192.168.1.1 | 255.255.255.0 |  |
| Router0 | S2/0 | 172.16.1.1 | 255.255.255.0 |  |
| Router1 | FastEthernet0/0 | 192.168.2.1 | 255.255.255.0 |  |
| Router1 | S2/0 | 172.16.1.2 | 255.255.255.0 |  |

配置完成后，先查看路由器初始路由表，判断为什么跨网段主机暂时不能通信。

### 4. 静态路由配置

在 Router0 上添加到 `192.168.2.0/24` 的静态路由：

```text
Router(config)# ip route 192.168.2.0 255.255.255.0 172.16.1.2
```

在 Router1 上添加到 `192.168.1.0/24` 的静态路由：

```text
Router(config)# ip route 192.168.1.0 255.255.255.0 172.16.1.1
```

查看路由表，确认静态路由生效，再测试 PC0 与 PC1 之间的连通性。

### 5. RIP 动态路由配置

删除静态路由后，配置 RIP 动态路由。以 Router0 为例：

```text
Router(config)# no ip route 192.168.2.0 255.255.255.0 172.16.1.2
Router(config)# router rip
Router(config-router)# network 192.168.1.0
Router(config-router)# network 172.16.1.0
```

Router1 同理发布 `192.168.2.0` 和 `172.16.1.0` 直连网络。配置完成后查看路由表，并再次测试主机互通。

## 实验任务

根据给定拓扑完成以下任务：

- 分配各子网网络号，配置子网内主机 IP 地址。
- 配置路由器串口 IP 地址。
- 分别使用静态路由和 RIP 动态路由完成路由表配置。
- 实现不同子网内主机之间的连通。

子网 1 网络号需要结合学号后四位设置：第二段使用学号后四位的前两位，第三段使用学号后四位的后两位。例如学号 `2023217408`，对应网络号可设计为 `*.74.8.0`。

## 常见错误

- 主机默认网关没有配置为所在网段的路由器接口地址。
- 路由器接口配置 IP 后未启用接口。
- 静态路由下一跳地址写错。
- RIP 只发布了一个直连网络，导致路由学习不完整。
- 地址规划时把不同子网配置到了同一网络号。
