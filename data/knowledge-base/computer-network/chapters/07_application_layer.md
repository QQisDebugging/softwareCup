# 第七章 应用层

## 学习目标

- 理解应用层协议如何直接服务用户应用。
- 掌握 Web 应用与 HTTP 的基本工作过程。
- 理解 DNS 和 DHCP 在网络访问中的作用。

## 先修知识

- 传输层端口和进程通信
- TCP 与 UDP 的基本区别
- 网络层地址和路由基础

## 核心概念

- Web 应用
- HTTP
- DNS
- DHCP

## 关键知识点

- 应用层协议定义应用进程之间交换报文的格式、顺序和语义。
- HTTP 是 Web 应用中浏览器和服务器交换请求与响应的核心协议。
- DNS 负责把便于记忆的域名解析为网络通信所需的 IP 地址。
- DHCP 用于为主机自动分配 IP 地址、子网掩码、默认网关、DNS 服务器等网络参数。
- 一次网页访问通常会涉及网络参数获取、域名解析、传输层连接和 HTTP 请求响应。

## 示例场景

一台刚连接校园网的笔记本先通过 DHCP 获取网络配置，然后通过 DNS 解析网站域名，最后通过 HTTP 与 Web 服务器交换网页数据。

## 常见错误

- 认为 DNS 负责传输网页内容。
- 混淆 DHCP 和 DNS 的作用。
- 只关注 HTTP 请求方法，忽略请求头、响应状态和报文格式。

## 实操任务

- 画出访问网站时 DHCP、DNS、HTTP 的调用顺序。
- 分析一个 HTTP 请求和响应中 URL、方法、状态码、请求头的含义。
- 对比 DNS 和 DHCP 的输入、输出和使用时机。

## 适合的学生画像

- 基础薄弱学生适合使用访问网站全过程流程图。
- 备考型学生适合做 DNS、DHCP、HTTP 职责辨析题。
- 实践型学生适合用浏览器开发者工具观察 HTTP 请求。
