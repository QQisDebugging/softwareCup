# 第五章 网络层

## 学习目标

- 理解网络层提供的服务类型。
- 区分网络层数据平面和控制平面。
- 掌握 IP、ARP、ICMP、NAT 的基本作用。
- 认识 RIP、OSPF、BGP 等路由协议的职责差异。

## 先修知识

- 网络体系结构和协议
- 链路层与局域网基本机制
- MAC 地址和局域网通信基础

## 核心概念

- 网络层服务类型
- 数据平面
- 转发
- IP
- ARP
- ICMP
- NAT
- 控制平面
- 路由
- RIP
- OSPF
- BGP

## 关键知识点

- 网络层负责实现跨网络的分组传输。
- 数据平面关注每个分组到来后如何转发，典型机制包括 IP、ARP、ICMP、NAT。
- 控制平面关注路由信息如何生成和维护，典型协议包括 RIP、OSPF、BGP。
- IP 提供主机和网络标识，是跨网络通信的基础。
- ARP 用于在局域网内把 IP 地址解析为 MAC 地址。
- ICMP 常用于差错报告和网络诊断，例如 ping。
- NAT 用于私有地址和公网地址之间的转换。
- RIP、OSPF、BGP 适用于不同规模和管理域的路由场景。

## 示例场景

学生从校园网访问外部网站时，主机先在局域网内完成下一跳转发，再通过路由器、NAT 和多个网络层转发设备到达目标网络。路由协议负责让网络设备知道应当选择哪条路径。

## 常见错误

- 把转发和路由混为一谈。
- 认为 ARP 能跨越多个网络工作。
- 不理解 ICMP 与 IP 的关系。
- 只记住 RIP、OSPF、BGP 名称，不能说明适用场景。

## 实操任务

- 使用 ping 观察 ICMP 的网络诊断作用。
- 绘制从私有地址主机访问公网服务时 NAT 的地址转换过程。
- 对比 RIP、OSPF、BGP 的应用范围。

## 适合的学生画像

- 基础薄弱学生适合先学习数据平面与控制平面对照表。
- 实践型学生适合做 ping、路由跟踪和地址转换流程分析。
- 进阶学生适合比较不同路由协议的设计目标。
