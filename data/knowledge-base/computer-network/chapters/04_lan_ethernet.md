# 第四章 广播链路与局域网

## 学习目标

- 理解广播链路中的共享介质访问问题。
- 掌握多路访问协议和随机接入协议的基本思想。
- 认识局域网和以太网的基本工作机制。

## 先修知识

- 链路层功能
- 帧与相邻节点通信

## 核心概念

- 广播链路
- 多路访问协议
- 随机接入协议
- 局域网
- 以太网

## 关键知识点

- 广播链路中多个节点共享同一通信介质，需要协调发送行为。
- 多路访问协议用于减少或解决多个节点同时发送造成的冲突。
- 随机接入协议允许节点竞争信道，典型问题是冲突检测和冲突恢复。
- 局域网通常覆盖较小范围，强调低时延和高吞吐。
- 以太网是最常见的局域网技术之一，围绕 MAC 地址和帧转发展开。

## 示例场景

在宿舍或实验室局域网中，多台设备通过交换机连接。主机发送数据时需要使用以太网帧和 MAC 地址完成局域网内通信。

## 常见错误

- 认为局域网通信只依赖 IP 地址。
- 混淆 MAC 地址和 IP 地址的作用。
- 不理解共享介质为什么会产生冲突。

## 实操任务

- 查看本机 MAC 地址、IP 地址和默认网关。
- 解释同一局域网内两台主机通信时 MAC 地址的作用。

## 适合的学生画像

- 实践型学生适合通过本机网络参数观察理解局域网。
- 图解偏好学生适合使用以太网帧格式和交换机转发示意图。

## 推荐资源类型

- 以太网帧结构图
- MAC 地址与 IP 地址对照表
- 局域网通信流程图
- 操作型实验指导

## 测评建议

- 检查学生是否能解释多路访问问题。
- 通过案例题考查 MAC 地址与 IP 地址的区别。
