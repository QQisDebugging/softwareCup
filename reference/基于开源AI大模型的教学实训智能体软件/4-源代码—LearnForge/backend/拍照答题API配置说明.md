# 拍照答题多API配置说明

## 功能概述

为了解决科大讯飞星火API不稳定的问题，我们为拍照答题功能添加了多个API支持，包括：

1. **科大讯飞星火** - 主要API，图像理解能力强
2. **百度AI图像识别** - 稳定的备用方案
3. **腾讯云OCR** - 需要配置密钥
4. **阿里云OCR** - 需要配置密钥
5. **通用OCR+AI解答** - 最后的备用方案

## 使用方法

### 1. 前端操作

1. 进入"拍照答题"页面
2. 点击"API配置"按钮
3. 在弹出的对话框中：
   - 查看各个API的状态
   - 启用/禁用不同的API
   - 调整优先级（数字越小优先级越高）

### 2. 系统行为

- 系统会按优先级自动选择可用的API
- 如果第一个API失败，自动尝试下一个
- 在结果页面会显示实际使用的API名称

### 3. API配置

#### 百度AI（推荐作为备用）
- 已经配置好，可以直接使用
- 使用项目现有的百度AI Token

#### 腾讯云OCR（可选）
如需使用腾讯云OCR，需要配置：
```bash
# 设置环境变量
export TENCENT_SECRET_ID="your_secret_id"
export TENCENT_SECRET_KEY="your_secret_key"
```

#### 阿里云OCR（可选）
如需使用阿里云OCR，需要配置：
```bash
# 设置环境变量
export ALI_ACCESS_KEY_ID="your_access_key_id"
export ALI_ACCESS_KEY_SECRET="your_access_key_secret"
```

## 配置文件

系统会自动创建 `backend/api_config.json` 文件来保存配置。

## 建议配置

推荐配置如下：

1. **科大讯飞星火** - 优先级1，启用
2. **百度AI图像识别** - 优先级2，启用
3. **通用OCR+AI解答** - 优先级3，启用
4. **腾讯云OCR** - 优先级4，根据需要启用
5. **阿里云OCR** - 优先级5，根据需要启用

## 故障排除

### 1. 科大讯飞星火连接失败
- 系统会自动切换到百度AI
- 用户会看到"[百度AI图像识别]"的提示

### 2. 所有API都失败
- 检查网络连接
- 确认至少有一个API配置正确
- 查看后端日志获取详细错误信息

### 3. 识别效果不佳
- 确保图片清晰、文字可读
- 尝试重新拍照或选择更清晰的图片
- 不同API的识别效果可能有差异

## 技术说明

### API优先级
- 系统按照优先级数字从小到大尝试API
- 只有启用的API才会被使用
- 如果所有API都失败，返回错误信息

### 配置持久化
- 所有配置更改都会自动保存到文件
- 重启服务后配置仍然有效

### 安全性
- 敏感信息（如API密钥）建议通过环境变量设置
- 配置文件不包含敏感信息
