# 智学工坊测试说明书

## 1. 测试环境

- Windows 11
- JDK 21
- Node.js
- Python 3.11+
- TeX Live 2024
- 后端默认 H2 文件数据库，可切换 PostgreSQL

## 2. 构建测试

### 2.1 后端构建

```powershell
$env:JAVA_HOME="D:\softwareCup\.runtime\jdk-21.0.11+10"
$env:Path="$env:JAVA_HOME\bin;$env:Path"
cd D:\softwareCup\backend
.\mvnw.cmd -DskipTests package
```

结果：`backend\target\backend-0.0.1-SNAPSHOT.jar` 构建成功。

### 2.2 前端构建

```powershell
cd D:\softwareCup\frontend
npm run build
```

结果：`frontend\dist` 构建成功。Vite 对大 chunk 给出性能提示，但不影响产物运行。

## 3. 服务健康检查

```powershell
Invoke-WebRequest http://localhost:8080/api/health
Invoke-WebRequest http://localhost:9001/health
Invoke-WebRequest http://localhost:5173/
```

预期：

- 后端返回 `status: UP`。
- 智能体返回健康状态。
- 前端首页 HTTP 200。

## 5. 非功能测试

- 页面文字不应溢出或被截断。
- 学生和教师操作边界清晰。
- 资源生成长任务必须显示进度，不出现白屏等待。
- 讯飞调用应启用缓存与每日限额，避免额度被误耗。
- 上传文件大小受后端限制保护。
