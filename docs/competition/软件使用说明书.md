# 智学工坊软件使用说明书

## 1. 启动方式

进入运行包目录，复制 `.env.example` 为 `.env` 并填写讯飞星火密钥，然后执行：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\start-zhixue-workshop.ps1
```

访问：

```text
http://localhost:5173/
```

停止：

```powershell
.\stop-zhixue-workshop.ps1
```

## 2. 默认账号

- 学生：`zhang.student` / `student@2026`
- 教师：`li.teacher` / `teacher@2026`

## 3. 学生端导航

学生端一级导航：

- 今日学习
- 我的课程
- 学习画像
- AI 助手
- 模型设置

学生端不单独设置“资源任务”入口。资源生成、任务进度和历史记录都归入 AI 助手或课程详情页。模型设置页可在讯飞星火与 OpenAI 兼容供应商（DeepSeek / 通义 / 智谱等）之间热切换。

## 4. 学生核心流程

### 4.1 今日学习

学生进入后查看当日建议学习时长、优先任务队列、可调计划和快速进入课程。点击“开始”进入对应课程或 AI 助手。

### 4.2 我的课程

课程来源分为两类：

- 班级课程：教师发放，学生加入班级后获得。
- 自建课程：学生上传资料后生成个人课程。

学生可以搜索课程、加入班级、创建自建课程、进入课程详情页。

### 4.3 课程详情页

课程详情页包含：

- 学习路径
- 章节资源
- 课程任务
- 课程 AI 助教

章节资源展示教师发放资源、AI 推荐资源和学生生成资源。学习路径按章节拆解并精准推送匹配资源；路径为空时可一键调用智能体生成。课程任务展示教师发布的作业与测试：测试在线作答并自动评分，作业文本提交并持久化记录。课程 AI 助教只围绕当前课程上下文工作，答疑支持 Mermaid 图解渲染。

### 4.4 学习画像

学习画像是跨课程综合画像，汇总学生在多个课程中的掌握度、学习习惯、优势、薄弱点和证据流。单课程画像在课程详情页内展示。

### 4.5 AI 助手

AI 助手采用课程项目空间模式。每门课程可以创建多个会话，并包含：

- 对话
- 生成资源
- 任务进度
- 历史记录

## 5. 教师端导航

教师端一级导航：

- 教学工作台
- 课程建设
- 资源审核
- 发布质检
- 智能体协同
- 班级画像

教师端保留资源审核和发布质检，因为教师承担发布、审核和质量门禁职责。

## 6. 教师核心流程

### 6.1 课程建设

教师上传教材、PPT、讲义、题库或实验资料，系统解析资料并生成课程章节结构和知识点草案。

### 6.2 资源审核

教师查看 AI 生成资源、审核证据、风险项和修订建议。审核通过后资源可发布给学生。

### 6.3 发布质检

发布前检查内容完整性、证据覆盖、敏感风险、章节匹配度和学生适配度。

### 6.4 智能体协同

教师查看多智能体执行阶段、任务进度、模型调用和异常情况。

## 7. 注意事项

- 正式演示前必须配置讯飞密钥。
- 首次启动 Python 智能体时会安装依赖，耗时取决于网络。
- 若资源生成失败，先检查后端日志、智能体日志和密钥配置。
- 若讯飞星火当日调用额度用尽，可在“模型设置”页热切换到已配置 Key 的 OpenAI 兼容供应商继续演示。
- 系统会拒绝任何降级/兜底结果入库，因此模型不可用时按钮会明确报错而非显示假数据。
