# 开源与第三方工具说明

## 1. 前端

- Vue 3：前端框架。
- Vite：前端构建工具。
- Pinia：状态管理。
- Vue Router：路由管理。
- Axios：HTTP 请求。
- Lucide Icons：图标库。
- ECharts：图表展示。
- Markdown-it：Markdown 渲染。
- Mermaid：图解/思维导图渲染（MIT 协议）。

## 2. 后端

- Spring Boot：后端应用框架。
- Spring Data JPA：数据访问。
- Flyway：数据库迁移。
- H2 / PostgreSQL：本地和生产可选数据库。

## 3. 智能体与 AI

- FastAPI：Python 智能体服务。
- Uvicorn：ASGI 服务。
- LangGraph / LangChain Core：多智能体流程编排和提示词链路。
- pypdf / python-docx：文档解析。
- 科大讯飞星火 API：正式大模型调用能力。

## 4. 演示与文档

- Beamer-HFUT：合肥工业大学 Beamer 幻灯片模板，来源为 `https://github.com/sxhfut/Beamer-HFUT`。
- TeX Live / XeLaTeX：演示文稿编译。
- Playwright：浏览器截图与页面验证。

## 5. 协议说明

上述工具均按照其公开协议和使用条款使用。项目提交包中保留本说明，正式提交前应结合最终依赖清单补充具体版本和许可证信息。
