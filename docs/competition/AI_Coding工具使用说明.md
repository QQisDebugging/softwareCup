# AI Coding 工具使用说明

## 1. 使用工具

项目开发过程中使用了 AI 辅助编程工具辅助完成需求拆解、代码生成、缺陷排查、文档整理和前端设计迭代，主要包括：

- OpenAI Codex：用于代码阅读、功能实现、脚本编写、测试验证和交付物整理。
- Playwright：用于浏览器截图、页面验证和交互检查。
- Image generation / product design workflow：用于生成登录页、学生端、教师端和 AI 助手的效果图，作为前端实现参考。
- 讯飞星火 API：作为正式智能体生成能力的模型提供方。

## 2. 使用边界

- AI 工具用于提高开发效率，不替代人工需求判断和最终验收。
- 所有关键代码改动均需经过构建或运行验证。
- 真实密钥不提交到仓库，只通过本地环境变量或 `.env` 注入。
- 生成内容需经过防幻觉审计和教师审核后发布给学生。

## 3. 对项目的贡献

- 快速梳理赛题要求，映射到系统模块与评分项。
- 生成多智能体任务链路和后端接口。
- 辅助完成学生端、教师端角色分离和课程中心架构设计。
- 生成 UI 概念图并辅助前端实现。
- 生成运行包、源码包、演示 PPT 和配套文档。

## 4. 风险控制

- 代码合并前执行 Maven 和 Vite 构建。
- 对页面效果进行浏览器截图检查。
- 对生成资源引入引用覆盖、敏感内容、事实性断言和人工复核门禁。
- 对讯飞调用启用缓存和每日调用限额，避免额度异常消耗。
