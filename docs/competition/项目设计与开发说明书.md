# 智学工坊：基于大模型的个性化资源生成与学习多智能体系统

> 中国软件杯 A3 赛题（科大讯飞）· 项目设计与开发说明书

## 1. 项目定位

智学工坊面向高校课程学习场景，以"课程"为中心，把**学生画像、课程资料、多智能体资源生成、个性化学习路径、智能辅导、学习效果评估**串成一个可运行、可追踪、可持续迭代的闭环平台。

系统不是单一聊天机器人，而是双端协同的学习工作区：

- **学生端**：在课程项目空间中获得个性化资源、章节学习路径、AI 助教答疑、作业测试与学情画像，形成"学—问—练—测—评"完整闭环。
- **教师端**：上传资料即可 AI 一键建设课程结构，资源经"课程诊断 + 内容安全"双重智能体审核后发布，班级画像智能体自动识别薄弱点与风险学生。

核心理念：用**多智能体协同 + 讯飞星火大模型 + RAG**，让"因材施教"在每一门课程、每一个学生身上真正落地。

## 2. 需求分析

### 2.1 学生痛点

- 学习资源来源分散，缺少与当前课程章节和个人能力匹配的筛选机制。
- 统一教学节奏难以兼顾不同基础、目标、认知风格和易错点。
- 练习、资料、答疑和复盘之间缺少连续闭环，学习行为数据无法反哺学习方案。

### 2.2 教师痛点

- 课程资源建设成本高，讲义、题库、导图、案例和实验材料需要重复加工。
- AI 生成内容需要可追溯证据、内容安全审核和发布质检，否则不敢直接给学生。
- 学生学习过程数据分散，难以形成可操作的学情判断与精准干预。

### 2.3 需求与前沿 AI 技术的结合点

| 需求 | AI 技术结合点 |
|------|--------------|
| 个性化画像 | 大模型对话抽取 + 多维度结构化输出 |
| 资源生成 | 多智能体角色分工 + RAG 课程知识库 + 多模态产物 |
| 路径规划 | 大模型对画像/进度/掌握度的综合推理 |
| 智能辅导 | RAG 限定课程资料 + Mermaid 图解 + 流式渲染 |
| 防幻觉 | 内容审计智能体 + 引用覆盖检测 + 发布门禁 |

## 3. 总体架构

系统采用 **Vue 3 前端 + Spring Boot 后端 + Python 多智能体服务**的三层架构，AI 能力独立成服务，便于编排与替换。

- **前端**：Vue 3、TypeScript、Pinia、Vue Router、Vite。负责学生端、教师端和课程工作区交互，支持 Markdown 渲染、Mermaid 图解、流式/进度展示、可拖拽分栏等现代 AI 交互。
- **后端**：Spring Boot、JPA、Flyway、H2/PostgreSQL。负责账号角色、课程、资源、作业测试、任务编排、画像、学习事件、疑惑文档和审核记录，并作为智能体调用的统一编排层与**发布质量门禁**。
- **智能体服务**：FastAPI、LangGraph/LangChain、文档解析、RAG 检索、讯飞星火调用。承载十余个角色智能体，负责画像抽取、知识诊断、资源生成、路径规划、班级分析和防幻觉审计。

```
┌─────────────────────────────────────────────────────────┐
│  Vue 3 前端：学生工作区 / 教师工作台 / 课程项目空间        │
│  （Markdown 渲染 · Mermaid 图解 · 流式进度 · 可拖拽分栏）  │
└───────────────────────────┬─────────────────────────────┘
                            │ REST
┌───────────────────────────▼─────────────────────────────┐
│  Spring Boot 后端：课程 / 资源 / 作业测试 / 任务编排      │

└───────────────────────────┬─────────────────────────────┘
                            │ HTTP（智能体调用，拒绝降级结果）
┌───────────────────────────▼─────────────────────────────┐
│  Python 多智能体服务：LangGraph 编排 + RAG + 内容审计     │
│  画像 / 诊断 / 路径 / 文档 / 题库 / 导图 / 实操 / 视频脚本 │
└───────────────────────────┬─────────────────────────────┘
                            │
┌───────────────────────────▼─────────────────────────────┐
│  讯飞星火大模型（可热切换至 OpenAI 兼容供应商）           │
│  课程知识库 / 上传文档 / 学习记录 / 模型调用证据          │
└─────────────────────────────────────────────────────────┘
```

## 4. 多智能体设计

资源生成任务被拆解为**可观测、可追溯**的协作链路，由后端统一编排调度，每一步都是真实的大模型调用：

| 智能体角色 | 职责 |
|-----------|------|
| ProfileInferenceAgent | 从对话、测评、学习事件抽取 8 个画像维度 |
| KnowledgeDiagnosisAgent | 识别课程知识短板、先修缺口与易错点 |
| PathPlanningAgent | 生成分阶段动态学习路径与资源推送顺序 |
| DocumentGenerationAgent | 生成课程讲解文档与章节讲义 |
| QuizGenerationAgent | 生成分层练习题、测验与解析 |
| MindMapAgent | 生成知识结构思维导图（Mermaid） |
| ReadingAgent | 生成拓展阅读材料 |
| PracticeCaseAgent | 生成代码实操案例 / 实验任务 |
| StoryboardAgent | 生成多模态教学视频 / 动画分镜脚本 |
| SlideGenerationAgent | 生成 PPT 课件草稿 |
| TutoringAgent | RAG 答疑，输出文字 + Mermaid 图解 + 后续建议 |
| ClassAnalyticsAgent | 班级画像分析、风险学生识别、干预建议 |
| ContentAuditAgent | 引用覆盖、事实断言、敏感内容检测与发布门禁 |

每个任务记录**步骤、事件、模型调用（provider/model/提示哈希）、审核结果和可发布资源**，杜绝"黑盒式"生成。

## 5. 讯飞星火接入与多模型热切换

正式运行使用科大讯飞星火 API；同时支持运行时**热切换**至 OpenAI 兼容供应商（DeepSeek / 通义 / 智谱 / Kimi 等），切换配置持久化、重启自动恢复。

关键环境变量：

- `XFYUN_API_PASSWORD` / `XFYUN_API_KEY` / `XFYUN_API_SECRET`
- `XFYUN_MODEL`
- `XFYUN_DAILY_CALL_LIMIT`
- `XFYUN_CACHE_ENABLED`
- `OPENAI_API_KEY` / `OPENAI_BASE_URL` / `OPENAI_MODEL`（OpenAI 兼容供应商）

系统支持提示词缓存与每日调用限额，便于在额度有限时完成稳定演示；前端"模型设置"页可视化切换供应商与模型。

## 6. 核心功能

### 6.1 对话式学习画像（赛题功能 1）

学生通过自然语言与 AI 对话，画像智能体自动抽取 **8 个维度**（知识基础、认知风格、学习目标、兴趣方向、易错点偏好、时间约束、资源偏好、掌握弱点），以雷达图等方式呈现，并随学习、答疑、测评事件**动态更新**，实现"随学随新"。

### 6.2 多智能体协同的多模态资源生成（赛题功能 2）

学生在课程项目空间上传 PPT、教材、讲义、PDF 或笔记，或教师在课程建设端上传资料。系统基于课程资料和学生画像，由不同角色智能体协作生成 **7 类资源**（≥赛题要求的 5 类）：

1. 课程讲解文档　2. 知识点思维导图（Mermaid 可视化）　3. 分层练习题库
4. 拓展阅读材料　5. 代码实操案例　6. 多模态教学视频/动画脚本　7. PPT 课件

生成全过程提供**进度追踪**：进度条、当前步骤、百分比实时刷新，自动跳转任务进度页，避免长时间白屏等待。

### 6.3 个性化学习路径规划与精准推送（赛题功能 3）

路径规划智能体结合课程章节、画像短板、掌握度与学习偏好，生成分阶段动态学习路径（导学→讲解→练习→项目）。点击任意章节，系统按画像精准推送该章节最匹配的文档、视频、练习；路径为空时可一键调用智能体实时生成。

### 6.4 智能辅导（赛题加分项 4）

课程 AI 助教围绕当前课程上下文，基于 RAG **严格限定本课程知识库**回答问题，输出：

- 流式 Markdown 文字解答
- **Mermaid 图解**（前端渲染为真实图形，多模态呈现）
- 资料依据引用（只引用本课程资料，杜绝跑题）
- 后续问题与学习行动建议

每轮答疑的疑惑会精炼沉淀为**该生该课程专属的疑惑文档**，反哺学习画像并供教师参考。

### 6.5 学习效果评估与课程任务（赛题加分项 5）

- **课程任务**：教师发布作业/测试，学生在课程内完成；测试自动评分，作业文本提交，提交记录入库持久化。
- **学情评估**：系统记录阅读、练习、答疑、资源生成、测评等学习事件，形成跨课程综合画像与单课程画像摘要，并根据测评反馈动态调整资源推送与学习路径。

### 6.6 教师端多智能体协同

- **课程建设**：上传资料 → AI 建议课程结构（章节树、知识点、学习目标）。
- **发布质量门禁**：提交发布须经过"AI 结构建议 + 课程诊断"双重智能体审核才能入库。
- **班级画像**：班级分析智能体输出薄弱知识点、风险学生与干预建议。

## 7. 防幻觉与内容安全

赛题明确要求"完善的防幻觉与内容安全过滤机制"，本系统的可信 AI 设计：

- **RAG 限定**：生成与答疑严格绑定课程资料/上传文档/检索证据，答疑只引用本课程资料。
- **审计智能体**：ContentAuditAgent 输出引用覆盖率、无依据断言、风险项、修订建议与人工复核门禁。
- **安全过滤**：黑名单规则检测密钥/隐私泄露、敏感违规、作业代写等内容。
- **后端拒绝降级**：后端对智能体产物校验 `fallbackUsed` 标记，**任何降级/兜底结果一律拒绝入库**，确保展示给师生的都是真实大模型产物。
- **调用可溯源**：记录模型、端点、提示哈希、缓存命中与错误信息；设置缓存与限额，避免盲目重复调用。

## 8. 部署方案

本地交付包包含：

- Spring Boot 可执行 jar
- Vue 构建后的静态文件
- Python 多智能体服务源码与 requirements
- 启动/停止脚本
- 示例课程数据与运行说明

默认端口：前端 `5173` · 后端 `8080` · 智能体 `9001`

数据库通过 Flyway 迁移自动建表并预置示例课程、资源、作业，确保开箱即有真实数据可演示。

## 9. 创新点

1. **课程为中心的 AI 项目空间**：不是孤立的资源任务入口，而是把画像、资料、生成、路径、答疑、测评收拢到每一门课程。
2. **真正的多智能体协同**：十余个角色智能体由 LangGraph 编排、后端统一调度，链路阶段/事件/模型调用/审核/发布状态全程可追踪。
3. **可信 AI 工程闭环**：RAG 限定 + 审计智能体 + 后端拒绝降级结果，从机制上保证"不幻觉、可溯源"。
4. **多模态与现代交互**：Mermaid 图解渲染、流式输出、生成进度追踪、可拖拽记忆布局，符合现代 AI 产品交互规范。
5. **双端协同 + 多模型热切换**：学生学习闭环与教师审核发布分离协同；支持讯飞星火与主流大模型运行时热切换，工程完整度高。
6. **学习闭环数据回流**：学习事件、测评、疑惑文档持续反哺画像与推送策略，实现学习方案的动态优化。
