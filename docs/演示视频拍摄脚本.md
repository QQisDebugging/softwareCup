## 1. 系统总览与多智能体架构（0:20–1:10）

**画面**：切到一张**架构图**（建议做成动画分层出现）
- 前端 Vue3 + TS（学生端 / 教师端）
- 后端 Spring Boot（接口编排、任务管理、发布质检闸门）
- AI 主程 FastAPI + LangGraph/LangChain（多智能体 + RAG）
- 讯飞星火大模型（可热切换至 OpenAI 兼容供应商）

**旁白**：
> "系统采用前后端分离 + 独立 AI 智能体服务的三层架构。核心是基于 LangGraph 编排的**多智能体协同框架**：画像智能体、资源生成智能体、路径规划、辅导、班级分析等十余个角色各司其职，由后端统一调度，全部由讯飞星火大模型驱动。"

**操作**：口头一句"系统支持讯飞星火等多模型热切换"带过即可。⚠️ **不要给"模型设置"页特写/停留**——当前演示实际运行的是备用供应商（星火额度用尽），设置页会显示第三方端点，避免穿帮。

## 2. 对话式学习画像自主构建（1:10–2:00）★必做功能1

**画面**：学生端"学习画像"页 → 发起一段自然语言对话
**操作脚本**：
1. 输入："我是计算机专业大二，学过 C 语言但 Java Web 基础薄弱，想系统补一下，平时喜欢看视频和案例。"
2. 点击生成 → **流式输出**画像摘要
3. 镜头扫过雷达图，强调**6 个以上维度**：知识基础、认知风格、易错点偏好、学习目标、学习节奏、动机水平

**旁白**：
> "告别繁琐表单。学生只需自然语言对话，画像智能体就自动抽取出**6 个维度**的动态画像，并随着后续学习、答疑、测评**持续更新**——这就是'随学随新'。"

**字幕标注**：✅ 对话抽取 · ✅ ≥6 维度 · ✅ 动态更新

## 3. 多智能体协同的多模态资源生成（2:00–3:20）★★核心重点，给足时长

**画面**：进入"资源生成"，基于上一步画像 + 选定课程发起生成
**操作脚本**：
1. 选择课程"Java Web 应用开发"，输入知识短板"HTTP 协议与请求响应"
2. 点击"生成" → **重点拍生成进度追踪 / 流式呈现**（避免白屏，正好呼应赛题非功能需求）
3. 镜头依次展示**至少 5 种资源类型**（卡片化展示）：
   - 📄 课程讲解文档（Markdown 渲染）
   - 🧠 知识点思维导图
   - 📝 分层练习题库（不同难度）
   - 💻 代码实操案例
   - 🎬 多模态教学视频/动画脚本（或拓展阅读）

**旁白**：
> "这是系统的核心。多个角色智能体协同工作——结合学生画像和课程知识库，通过 RAG 检索本课程资料，由不同智能体分别产出**讲解文档、思维导图、分层题库、代码实操、多模态视频脚本**等五类以上个性化资源。注意右侧的**生成进度追踪**，每一步都是真实的大模型调用，可回看每个智能体的 provider 和产物。"

**字幕标注**：✅ 多智能体协同 · ✅ ≥5 种资源 · ✅ 多模态 · ✅ 流式/进度

> 💡 拍摄建议：这段是 45% 功能分的核心，**让真实生成跑完一次**，哪怕慢也要展示进度条，体现"真 AI 不是模板"。

## 4. 个性化学习路径规划与精准推送（3:20–4:10）★必做功能3

**画面**：进入某门课程详情 → "学习路径"标签
**操作脚本**：
1. 展示**自动拆解的章节路径**（导学→讲解→练习→项目，带进度状态）
2. 点击某一章节 → 右侧**联动推荐该章资源**（课程资料 + 高分网课 + 文档，按画像精准匹配）
3.（可选）演示路径为空时点"生成学习路径"→ 调用路径规划智能体实时生成

**旁白**：
> "路径规划智能体整合所有生成资源，结合学生画像、学习进度和掌握情况，规划出科学有序的学习步骤。点击任意章节，系统会**精准推送**该章节最匹配的文档、视频、练习——千人千面的学习路线。"

## 5. 智能辅导 + 学习效果评估闭环（4:10–5:00）★加分项4/5

**画面**：课程内"AI 助教" → 提问
**操作脚本**：
1. 提问"HTTP 状态码 404 和 500 有什么区别？"→ **流式 Markdown 回答**
2. 强调回答带**资料依据（RAG 引用本课程资料）**，且只引用本课程
3. 切到"课程任务"→ 打开一份**测试**，作答提交 → **自动评分**（参考学习通体验）
4. 一句话带过：答疑中的疑惑会沉淀为该生该课程的**疑惑文档**，反哺画像与教师

**旁白**：
> "学习中遇到问题，课程 AI 助教基于 RAG 给出带**资料依据**的多模态解答，确保不跑题、不幻觉。完成测试后系统自动评分，学习行为、测评结果实时回流，**动态评估学习效果并调整推送策略**，形成'学—问—测—评'的完整闭环。"

## 6. 教师端多智能体协同（5:00–5:50）★创新/实用

**画面**：切换到教师角色
**操作脚本**：
1. **课程建设**：上传资料 → 点"AI 建议结构" → 智能体生成章节树/知识点/学习目标
2. **发布质检**：提交发布时，系统强制经过**AI 结构建议 + 课程诊断**双重智能体审核才入库
3. **班级画像**：点"刷新画像"→ 班级分析智能体输出薄弱知识点、风险学生、干预建议

**旁白**：
> "系统不只服务学生。教师端同样由多智能体驱动：上传资料即可 **AI 一键建议课程结构**；发布前经过**课程诊断智能体质检**才能上线；班级画像智能体自动识别**薄弱点和风险学生**，给出干预建议——大幅减轻教师负担。"
