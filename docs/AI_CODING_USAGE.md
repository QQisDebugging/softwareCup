# AI Coding 使用说明

本项目开发过程中可使用 AI Coding 工具辅助完成代码生成、重构、接口联调和文档整理。

## 当前说明

- 本地主要开发环境：VS Code / Codex。
- 比赛要求的科大讯飞相关工具：项目运行侧将接入讯飞星火大模型，作为资源生成、学习辅导和学习效果分析的模型提供方。
- AI 生成代码必须经过人工审查、编译验证和接口联调后提交。
- 不提交任何真实 API Key、数据库密码或学生隐私数据。

## 可在最终文档中呈现的使用边界

- AI Coding 用于搭建 Spring Boot 基础结构、生成 DTO、补充文档和测试样例。
- 核心架构、数据表设计、接口契约、比赛演示流程由团队确认。
- 对大模型输出的学习资源需要人工抽检，避免知识错误和不适合学生水平的内容。
