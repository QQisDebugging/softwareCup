# Java 后端主程范围

## 当前已落地

- Spring Boot 后端工程。
- H2 默认本地数据库和 PostgreSQL profile。
- Flyway 迁移脚本。
- 学习画像接口。
- 课程与学习资源接口。
- 资源生成任务状态机：`PENDING`、`RUNNING`、`SUCCEEDED`、`FAILED`。
- 文件上传和上传元数据记录。
- 后端调用 Python 资源生成智能体的 HTTP 契约。

## 下一阶段后端任务

1. 接入真实登录和学生账号体系。
2. 把课程 JSON 导入做成初始化脚本或后台管理接口。
3. 增加学习路径规划任务表和接口。
4. 增加智能辅导会话表、答疑记录表和反馈表。
5. 增加学习效果评估事件表，包括资源浏览、练习提交、测试得分和主观反馈。
6. 接入讯飞星火真实调用，并记录 prompt、模型、耗时、token 或计费字段。
7. 用接口测试覆盖核心链路。
