# 智学工坊页面逻辑规划

## 总原则

- 首页不是导航壳。学生首页必须能直接完成今日规划、课程筛选、任务排序和轻量问答。
- 只有进入完整阅读、上传资料、资源生成、教师审核这类长流程时才跳转。
- 学生端和教师端功能分离：学生看自己的课程、画像、资源和助教；教师看班级、发布、审核和学情。
- 课程来源分两类：班级发放课程由老师或班级码进入；我的自建课程由学生上传资料生成。
- AI 能力要在页面中可见：每个核心页面都要呈现 Agent 正在做什么、输入是什么、输出是什么。

## 学生端

### 学生主页 `/dashboard`

定位：学习工作台，而不是课程详情页。

核心内容：
- 所有课程入口：展示班级发放和我的自建课程，可筛选，可快速加入今日规划。
- 今日规划助手：默认给出今日学习安排，支持在本页继续询问课程、薄弱点、练习和资源整理。
- 今日待办：跨课程排序，学生可以把任务加入规划，也可以打开对应完整页面。
- 课程来源说明：明确加入班级课程与上传资料生成课程两条路径。

跳转规则：
- 统计卡、今日任务、AI 快捷项默认只更新本页规划助手。
- `查看课程` 跳 `/courses`。
- `创建课程` 跳 `/course-builder`。
- `完整助教` 跳 `/learning`。

### 课程空间 `/courses`

定位：课程内容阅读和资源库。

核心内容：
- 左侧课程列表与章节树。
- 中间阅读资源正文、题库、案例、导图。
- 右侧课程内行动：进入 AI 助教、生成补充资源、下载正文。

不承担：
- 不做跨课程今日规划。
- 不承担教师审核发布。

### 自定义课程 `/course-builder`

定位：课程来源管理和资料生成课程。

核心内容：
- 加入班级课程：输入班级码或接受教师邀请。
- 上传资料生成课程：上传 PPT、教材、讲义、题库，生成章节、知识点、练习和资源。
- 模板槽位：保留通用结构，不绑定单一课程样例。

### 学习画像 `/profiles`

定位：学生画像解释和证据管理。

核心内容：
- 当前画像维度、证据来源、置信度。
- 对话、测评、学习行为、教师证据记录。
- 可补充证据，不作为课程阅读主页面。

### 资源生成 `/generation`

定位：Agent 资源生成任务台。

核心内容：
- 选择课程、画像、资源类型和目标。
- 显示 Agent 流程：资料检索、画像匹配、资源生成、内容审核、发布或保存。
- 显示任务历史和进度。

### AI 助教 `/learning`

定位：完整对话学习空间。

核心内容：
- 大聊天区为主体。
- 可引用当前课程、资料、任务、画像。
- 支持讲解、出题、批改、复盘。

## 教师端

### 教学工作台 `/teacher`

定位：班级教学和发布工作台。

核心内容：
- 班级课程、学生概况、待审核资源、待发布任务。
- 进入教师侧课程建设、资源审核、班级画像。

### 班级画像 `/profiles`

定位：教师查看班级维度画像。

核心内容：
- 班级薄弱点、学生分层、证据链。
- 面向教学调整，不混入学生个人操作入口。

### 资源审核 `/generation`

定位：教师审核 AI 生成内容。

核心内容：
- 待审核资源列表、差异检查、发布给学生。
- 不展示学生自助生成入口。

### 智能体协同 `/agents`

定位：展示和调试 Agent 编排。

核心内容：
- 各 Agent 的输入、输出、状态和日志。
- 面向教师/管理员，不给学生普通学习入口。

### 发布质检 `/quality`

定位：发布前质量检查。

核心内容：
- 内容安全、结构完整性、课程匹配、引用来源检查。

## 当前实现优先级

1. 学生主页先做成可用工作台，减少无意义跳转。
2. AI 助教页改成聊天主体。
3. 自定义课程页理清“加入班级”和“上传生成”两条路径。
4. 课程空间做成正式阅读/资源页。
5. 教师端页面按发布、审核、班级画像拆清楚。
